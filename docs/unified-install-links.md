# 统一安装地址

每个应用类型（如 Beta、Production）都有一个独立的统一安装入口，避免把不同环境的安装包混在一起。

## 设置

1. 打开应用详情，点击对应类型“统一安装地址”旁的“设置”按钮（或卡片右下角的编辑按钮）。
2. 在“统一安装地址”中填写自定义链接后缀，例如 `ZOCharge`。
3. 选择此类型下的 Android、iOS 渠道。每个平台只有一个渠道时可保留“自动选择唯一渠道”；同平台有多个渠道时必须明确选择。
4. 保存后，类型卡片会显示统一安装链接和固定短链接。

同一个入口在 Android 上进入 Android 渠道，在 iPhone、iPad（包括桌面模式的 iPad）上进入 iOS 渠道；电脑或未知设备会看到平台选择和二维码。入口始终指向对应渠道的最新版本。加上 `?choose=1` 可在手机上打开平台选择页。

## 自定义后缀与兼容

- 统一入口有不可修改的固定短码，也支持自定义后缀。两者都能使用。
- 编辑渠道时也可以设置单端渠道的自定义后缀；原渠道短链接继续有效。
- 修改或清空自定义后缀后，曾经保存过的后缀仍然有效。修改渠道原短码也会保留旧地址。
- 链接不区分大小写，整个站点共用一个唯一命名空间，禁止占用 `apps`、`api`、`users` 等系统路径。
- 后缀长度为 1–64，首位为英文字母或数字，其余支持英文字母、数字、短横线、下划线。
- 删除所属应用、类型或渠道时，其相应链接会一并移除；归档应用的统一入口及别名不可访问。
- 原有渠道短链接继续指向该单端渠道；统一入口的固定短码和自定义后缀负责双端识别。

## 入口访问限制

每个类型独立设置“公开访问”“访问密码”或“仅应用成员”。固定短链接、自定义后缀与历史后缀共用此权限，不要求绑定的 Android、iOS 渠道公开。

- 公开访问：访客可直接浏览和安装所绑定的平台。
- 访问密码：访客需先验证入口密码，应用成员可直接进入。密码为 BCrypt 摘要，保存时留空保留原密码；修改密码后旧会话和安装凭据失效。
- 仅应用成员：登录且具有该应用访问权限的成员才能安装。锁定用户、撤销成员资格或归档应用后不再允许访问。

统一安装页、下载、二维码与 iOS 安装清单均使用统一入口权限。单端渠道原地址、版本页和下载接口仍按渠道原有权限检查；访问统一入口不会向浏览器写入渠道解锁凭据。

iOS 安装器使用有效期 10 分钟、绑定入口和版本的签名凭据获取清单与本地安装包。更改入口权限、密码或平台绑定使旧凭据失效；成员入口还会重新检查成员身份。S3 下载使用存储配置的有效期或公开对象地址。

新类型默认“仅应用成员”。迁移 `20261027000002` 将旧“沿用渠道设置”改为“仅应用成员”，管理员可再明确选择公开访问。已有密码入口和成员入口保留各自模式。

## API

类型更新接口接受 `install_alias`、`android_channel_id`、`ios_channel_id`、`install_access`（`public` / `password` / `members`）、`install_password`，返回 `install_code`、`install_alias`、`install_path` 、`install_access` 及平台渠道绑定（不返回密码或密码摘要）。渠道更新接口接受 `install_alias`，返回 `install_alias` 和 `install_path`。未授权、重复或非法后缀均会被拒绝，且不改变原有配置。

## 数据与部署

迁移 `20261027000000` 新增 `public_links`，在类型上增加固定短码、自定义后缀和双端绑定，在渠道上增加自定义后缀。迁移会登记所有已有渠道短码，并为已有类型分配固定统一短码。迁移 `20261027000001` 为类型增加入口访问模式和密码摘要，已有记录默认沿用渠道设置。历史别名留在 `public_links` 中；不依赖 S3 文件或浏览器本地数据。

部署前备份数据库和 Compose 配置，停止应用写入后再迁移、启动新版本。若在开放流量前启动失败，可回退此次迁移和应用镜像。开放流量后若产生新别名或绑定，不要直接恢复旧数据库覆盖业务写入；应保留新表和字段，使用兼容此迁移的修复镜像。

## 验证

在 `zealot-s3-test-db` 隔离数据库上，以旧镜像创建名为 `Legacy Android` 的公开 Android 渠道后，使用新镜像迁移，再运行：

```sh
bundle exec rails runner test/s3/unified_install_links.rb
```

覆盖历史数据迁移、Android/iPhone/iPad 自动跳转、桌面入口、二维码、自定义后缀与历史别名、最新版本、命名冲突、平台绑定、分享权限、归档、删除、管理表单及 API。浏览器验收脚本为 `test/ui/unified_install.cjs`，使用隔离环境中的演示应用，在明暗主题和手机、平板、桌面及横屏尺寸下检查页面和管理表单。
